Theoretical Focus: File System Operations, System Signals & Safe Subprocess Execution
1. Main concepts

1. File System Operations using pathlib

pathlib is a Python module used to work with files and directories. It allows you to find files, check whether paths exist, create directories, and inspect file information.

Important methods:

Path.exists() — checks whether a path exists.

Path.is_file() — checks whether a path is a file.

Path.iterdir() — lists items in a directory.

Path.rglob() — recursively searches directories.

Path.stat() — retrieves file metadata.

2. File Metadata and Stale Log Detection

File metadata provides information about a file, such as its size and timestamps. A stale log file is a log file that has not been modified for a defined period.

Important attributes:

st_size — file size in bytes.

st_mtime — last modification timestamp.

st_ctime — creation time on Windows; metadata-change time on Unix-like systems.

3. System Signals and Process Termination

A process is a running program. Signals communicate events or termination requests to processes.

SIGINT — interruption, commonly caused by pressing Ctrl + C.

SIGTERM — requests graceful termination.

SIGKILL — forcefully terminates a process on supported systems; it is not available on Windows.

Python provides the signal module to handle supported signals and the subprocess module to manage external processes.

4. Safe System Binary Execution using subprocess

The subprocess module allows Python to execute external programs and system utilities.

subprocess.run() — executes a command and normally waits for it to finish.

subprocess.Popen() — starts a process and allows you to manage it.

check=True — raises an exception if the command exits with a nonzero status.

shell=False — avoids running the command through a shell.

5. Shell Injection and Secure Command Execution

Shell injection occurs when untrusted input is interpreted as part of a shell command, potentially allowing unintended commands to run.

To reduce this risk, use argument lists instead of concatenating user input into command strings, keep shell=False, validate inputs, and use trusted executables.
