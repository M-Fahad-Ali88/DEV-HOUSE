1. cProfile
Definition

cProfile is Python's built-in CPU profiling tool that measures how much execution time each function takes and how many times it is called during a program's execution.

Purpose

The purpose of cProfile is to identify performance bottlenecks by showing:

Which functions consume the most CPU time.
How many times each function is executed.
Where the program spends most of its execution time.
Which functions should be optimized to improve performance.

2. pstats
Definition

pstats is a Python module that analyzes, sorts, and formats the profiling data generated by cProfile.

Purpose

The purpose of pstats is to make profiling results easier to understand by:

Sorting functions by execution time or cumulative time.
Displaying the slowest functions.
Filtering and organizing profiling statistics.
Helping developers identify the most expensive operations.
3. tracemalloc
Definition

tracemalloc is Python's built-in memory allocation tracing module that tracks where memory is allocated and measures current and peak memory usage.

Purpose

The purpose of tracemalloc is to identify memory-related issues by:

Tracking current and peak memory usage.
Detecting memory leaks.
Finding the lines of code responsible for memory allocations.
Comparing memory snapshots before and after program execution.
4. py-spy
Definition

py-spy is an external sampling profiler for Python that analyzes a running Python program without requiring any changes to its source code.

Purpose

The purpose of py-spy is to:

Identify CPU bottlenecks in running applications.
Monitor performance with very low overhead.
Profile production applications safely.
Generate flame graphs and live performance reports.
Debug slow or unresponsive Python programs without stopping them.
Quick Comparison
Tool	Definition	Main Purpose
cProfile	Built-in CPU profiler that records function execution time and call counts.	Find slow functions and CPU bottlenecks.
pstats	Module for analyzing and formatting cProfile results.	Sort and present profiling statistics clearly.
tracemalloc	Built-in memory allocation tracker.	Detect memory leaks and monitor memory usage.
py-spy	External sampling profiler for running Python processes.	Analyze performance and CPU usage with minimal overhead, even in production.
