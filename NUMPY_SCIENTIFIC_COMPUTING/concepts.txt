NumPy Scientific Computing – Complete Theory
Theory 1: Scientific Computing with NumPy
1. What is Scientific Computing?
Scientific computing is the use of computers to solve mathematical, scientific, and engineering problems through numerical calculations.

It involves:
- Mathematical computations.
- Large datasets.
- Statistical analysis.
- Matrix operations.
- Numerical simulations.
- Financial calculations.
Example:

Suppose we have stock prices for 1 million trading observations. We want to calculate their average, standard deviation, and daily returns.

Performing these calculations manually or through ordinary Python loops can be inefficient.

This is where NumPy becomes useful.
2. What is NumPy?
NumPy (Numerical Python) is a Python library designed for efficient numerical computing.

Its primary data structure is the ndarray (N-dimensional array).

Unlike ordinary Python lists, NumPy arrays are designed to store numerical data efficiently and perform operations on entire collections of values.
3. Python Lists vs NumPy Arrays
Consider these two data structures:

Standard Python list:
numbers = [10, 20, 30, 40, 50]



NumPy array:
numbers = np.array([10, 20, 30, 40, 50])



Their fundamental differences:
Feature	Python List	NumPy Array
Data types	Can contain mixed types	Generally homogeneous
Memory	Higher overhead	More memory-efficient
Mathematical operations	Often require loops	Supports vectorized operations
Performance	Slower for large numerical operations	Generally faster
Multidimensional data	Nested lists	Native N-dimensional arrays

4. Why is NumPy Faster?
There are several reasons:
1. Contiguous numerical storage: NumPy can store array elements in compact memory regions.
2. Vectorization: Operations can process entire arrays without explicit Python-level loops.
3. Compiled implementation: Many numerical operations execute through optimized compiled code.
4. Reduced Python overhead: NumPy avoids repeatedly interpreting individual numerical operations in Python loops.
An important distinction: NumPy is not automatically faster for every operation. Performance depends on array size, operation type, memory layout, and implementation.
5. What is Scientific Computing Used For?
- Machine learning and artificial intelligence.
- Financial market analysis.
- Scientific simulations.
- Image processing.
- Statistical calculations.
- Engineering applications.
- Data analysis.
Key takeaway: NumPy provides an efficient foundation for numerical computing, especially when working with large datasets and mathematical operations.

Theory 3: Memory Strides
This is one of the most important concepts in advanced NumPy.
1. What are Memory Strides?
Memory strides describe how many bytes NumPy must move in memory to access the next element along a particular dimension.

In simple words:

Strides tell NumPy where the next element is located in memory.

Consider a 2D array:
[[10, 20, 30],
 [40, 50, 60]]


Assume each element occupies 8 bytes (float64).

Its memory layout in C-order is conceptually:
10 → 20 → 30 → 40 → 50 → 60


The strides would be:
(24, 8)


Why?
- 24 bytes to move to the next row.
- 8 bytes to move to the next column.
2. How Are Strides Calculated?
For a C-contiguous 2D array with 3 columns and 8-byte elements:
\[
\text{Row stride}=3\times8=24
\]

\[
\text{Column stride}=8
\]

Therefore:
\[
\text{Strides}=(24,8)
\]

For an array with shape (2, 3):
Dimension	Stride
Rows	24 bytes
Columns	8 bytes

3. Why Are Strides Important?
Strides allow NumPy to access elements without necessarily rearranging or copying the underlying data.

For example, when you transpose a matrix, NumPy can often create a new view with different strides rather than physically rearranging all its elements.

This is an important optimization.
4. Views vs Copies
View: A new array object that references the same underlying data.

Copy: A separate array with its own data storage.

Why does this matter?
- Views can save memory.
- Copies require additional memory.
- Modifying a view can affect the original array.
- Modifying an independent copy does not affect the original.
Key takeaway: Strides explain how NumPy navigates memory and are essential for understanding array performance, views, and transposition.

Theory 4: Contiguous Memory Layouts
1. What is Contiguous Memory?
Contiguous memory means that array elements are arranged sequentially in a continuous block of memory according to a particular layout.

NumPy supports two major memory layouts:
- C-order (Row-major).
- Fortran-order (Column-major).
2. C-Order (Row-Major)
In C-order, elements from the same row are stored consecutively.

Consider:
1  2  3
4  5  6


Memory arrangement:
1 → 2 → 3 → 4 → 5 → 6


The first row is stored before the second row.








cnblogs.com


3. Fortran-Order (Column-Major)
In Fortran-order, elements from the same column are stored consecutively.

For the same matrix:
1  2  3
4  5  6


Memory arrangement:
1 → 4 → 2 → 5 → 3 → 6










labs.quansight.org


4. Difference Between C-Order and Fortran-Order
Feature	C-Order	Fortran-Order
Storage	Row-major	Column-major
Consecutive elements	Same row	Same column
First dimension	Slower-changing	Faster-changing
Common usage	Python and C libraries	Fortran numerical libraries

5. What is a Non-Contiguous Array?
A non-contiguous array does not occupy a single sequential memory region in the order expected by its current shape and strides.

For example, selecting every second column from a matrix can create a non-contiguous view.

This means:
- Some memory accesses may be less efficient.
- Certain operations may require copying data.
- Performance can depend on the memory access pattern.
6. Why Does Memory Layout Matter?
Imagine processing millions of numerical values.

If the CPU accesses neighboring memory locations, it can benefit from CPU cache behavior.

This is called cache locality.

Good memory locality can improve performance because nearby values are more likely to be available in faster CPU cache memory.

Key takeaway: Memory layout determines how array elements are physically organized and can significantly influence numerical performance.

Theory 5: Vectorization and Broadcasting
This is the most important concept for our practical tasks.
1. What is Vectorization?
Vectorization means performing operations on entire arrays instead of writing explicit Python loops to process individual elements.

Consider adding two arrays.

Standard Python approach:
a = [10, 20, 30]b = [1, 2, 3]result = []for i in range(len(a)):    result.append(a[i] + b[i])



NumPy vectorized approach:
result = a + b



Here, assume a and b are NumPy arrays.

Output:
[11 22 33]


The operation applies to all corresponding elements.
2. Why is Vectorization Faster?
In ordinary Python loops, each iteration involves Python interpreter overhead.

NumPy performs many numerical operations through optimized compiled implementations.

Therefore, vectorization can significantly reduce execution time for large numerical arrays.
3. What is Broadcasting?
Broadcasting is a NumPy mechanism that allows operations between arrays of different shapes when their dimensions are compatible.

It allows NumPy to perform calculations without manually repeating values.

Consider:
Array A = [10, 20, 30]

Scalar = 5


Operation:
A + 5


Result:
[15, 25, 35]


NumPy effectively applies the scalar to every element.
4. Broadcasting Between Different Dimensions
Consider:
A = [[10],
     [20],
     [30]]

B = [1, 2, 3]


Their shapes are:
A = (3, 1)
B = (3,)


After broadcasting, they behave as compatible shapes:
A = [[10, 10, 10],
     [20, 20, 20],
     [30, 30, 30]]

B = [[1, 2, 3],
     [1, 2, 3],
     [1, 2, 3]]


Addition produces:
[[11, 12, 13],
 [21, 22, 23],
 [31, 32, 33]]


Notice that we did not manually create these repeated arrays. Broadcasting handles the compatible dimensions conceptually.
5. Broadcasting Rules
NumPy compares array dimensions from right to left.

Two dimensions are compatible when:
1. They are equal.
2. One of them is 1.
For example:
Shape A	Shape B	Compatible?
(3, 4)	(3, 4)	Yes
(3, 4)	(1, 4)	Yes
(3, 4)	(3, 1)	Yes
(3, 4)	(4,)	Yes
(3, 4)	(2, 4)	No

6. Broadcasting vs Vectorization
These concepts are related but different.
Vectorization	Broadcasting
Applies operations to arrays efficiently	Allows compatible shapes to work together
Reduces explicit Python loops	Handles dimension compatibility
Focuses on efficient computation	Focuses on array shape compatibility


6. Financial Computing Concepts
Our final technical task will use broadcasting and vectorized operations to calculate financial metrics.

Before implementation, understand these two formulas.
A. Logarithmic Returns
Logarithmic returns measure the change in an asset's price using the natural logarithm.

Formula:
\[
r_t=\ln\left(\frac{P_t}{P_{t-1}}\right)
\]

Where:
- \(r_t\) = Logarithmic return.
- \(P_t\) = Current price.
- \(P_{t-1}\) = Previous price.
- \(\ln\) = Natural logarithm.
Example:

Suppose:
- Previous price = 100.
- Current price = 110.
\[
r_t=\ln(110/100)
\]

\[
r_t=\ln(1.1)
\]

\[
r_t\approx0.09531
\]

The logarithmic return is approximately 9.53%.
B. Rolling Volatility
Rolling volatility measures how much returns fluctuate over a moving window of observations.

It is generally calculated using standard deviation.

Population standard deviation:
\[
\sigma=\sqrt{\frac{\sum_{i=1}^{n}(r_i-\mu)^2}{n}}
\]

Where:
- \(\sigma\) = Volatility.
- \(r_i\) = Individual return.
- \(\mu\) = Mean return.
- \(n\) = Number of observations.
For financial applications, sample standard deviation may also be used, depending on the methodology.

What does rolling mean?

Suppose we have daily returns:
[0.02, 0.03, -0.01, 0.04, 0.01]


With a rolling window of 3:
- Window 1: First 3 returns.
- Window 2: Next 3 returns.
- Window 3: Last 3 returns.
Each window produces its own volatility measurement.
