Daily Tasks
1. Build asynchronous TCP socket connections and HTTP engine interfaces using aiohttp

Definition: Build non-blocking TCP and HTTP connections that can send and receive data concurrently using the aiohttp library.

Purpose: To perform fast and efficient network communication without blocking the application.

2. Implement custom asynchronous context managers (__aenter__, __aexit__) for safe network resource management

Definition: Create custom async context managers that automatically acquire and release network resources using the async with statement.

Purpose: To ensure network sessions and connections are properly opened and closed, preventing resource leaks.

Definition: Implement fixed timeout limits and automatic retry logic to handle failed or delayed network requests.

Purpose: To make applications reliable by recovering from temporary server failures and preventing indefinite waiting.

🚗 Ride-sharing apps retry GPS or map requests.
